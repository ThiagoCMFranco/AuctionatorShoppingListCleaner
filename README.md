This is a World of Warcraft addon.  

A simple plugin for Auctionator that allows you to select and delete multiple Auction House shopping lists at once.

Game Addon Categories: Auction & Economy, Plugins, Miscellaneous.  

Currently Supported Languages:   
Full Support:
- Brazilian Portuguese (ptBR) - Developer Native Language  
- English (enUS) - 100% translated  

Dependencies: Auctionator (https://www.curseforge.com/wow/addons/auctionator) 

## Main Features
Add a button to the Auctionator's Auction House interface allowing to remove shopping lists and items for any of those lists in a bulk.
Allow viewing Auctionator shopping lists filter rules outside of the Auction House.

## Controls, Configurations, Commands and Usability Features
Use the following slash command to control the addon.  
/AuctionatorShoppingListCleaner: Toggle Auctionator Shopping List Cleaner Panel.  
/ASLC: Toggle Auctionator Shopping List Cleaner Panel.
